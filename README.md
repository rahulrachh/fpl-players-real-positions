# FPL Real Shape Visualizer

## Summary
FPL shows a team as a tidy formation, but managers pick attacking "defenders" and "midfielders". This app plots where a team's players actually played, using real per-match average positions from Sofascore. Enter an FPL team ID, see the team's real shape for the latest gameweek, step back through earlier gameweeks, and export the graphic as an image. Data is refreshed by an offline script and shipped with each deployment. Planner mode and the Claude roast are planned for v1.

- **Task 10 — Position logic I: frame, last match played, ghosts** (done 2026-10-17): `backend/app/logic/positions.py` holds pure functions on plain dataclasses. It is the one place the 0-100 attacking-upward frame is defined in code (`CENTER_X`, `validate_point`). `place_player()` / `place_players()` give each player a `Placement` for a target gameweek: every usable match of that GW (a double GW keeps both), otherwise his most recent usable earlier match by kickoff with a `from_gw` label, otherwise a ghost (`no_match`, or `no_mapping` when there is no Sofascore link). Later and unlinked matches are ignored. `backend/app/logic/repository.py` loads mappings and rows using the (player, kickoff) index (checked by a test). New `POSITION_MIN_POINTS_COUNT` setting (default 1) decides whether a match is usable. Real DB: all 436 active players placed for GW6/GW7, 0 ghosts. Docs: `docs/position-logic.md`. 169 tests pass.

- **Task 11 — Position logic II: gameweek states, auto-subs, double gameweek** (done 2026-10-17): `backend/app/logic/gameweek.py` turns a team's gameweek into dots. **Locked** = finished in FPL and `positions_synced`, else **preview** (also finished-but-not-synced). Preview draws the XI as picked (auto-subs undone from FPL's `automatic_subs`), each from his most recent match with a "from GWx" label unless it is from the previous (or target) GW. Locked draws the XI after auto-subs (sub-in in the starter's slot, `replaces` set) from that GW's matches only; a starter with none is a ghost. Double gameweek: two linked dots when the matches are on opposite flanks beyond the new `DGW_FLANK_MARGIN` (default 10), else one averaged dot. Armband on the picked captain (preview) or the multiplied player (locked). `load_positions_synced()` in the repository. Real data: owner's team GW1-6 locked, 11 dots, no ghosts; auto-subs checked on two other teams. Docs: `docs/position-logic.md`. 195 tests pass.
